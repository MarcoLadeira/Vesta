# Workflow: settings tour

**Recording:** `recordings/04-settings-tour.webm`
**Screens:** `screens/settings/SETTINGS-GENERAL-001` … `SETTINGS-TOOLS-EXPANDED-008`, `screens/providers/PROVIDERS-CONNECTED-001`, `screens/permissions/PERMISSIONS-SAFETY-001`

1. Clicking the header **Settings** gear opens a full-window settings view:
   a branded left rail ("Vesta — Code faster together.", search field) with
   grouped pages — **Vesta** (General, Appearance), **AI** (Models &
   Routing, Agents, Usage & Budgets), **Development** (Workspace,
   Integrations), **Trust** (Safety & Privacy), **System** (Advanced) — and
   a back-to-chat button.
2. Each rail click swaps the right-hand pane and moves the active marker.
3. **Integrations** hosts the Connection Doctor (per-provider status badge,
   Test and Sign-in buttons) plus GitHub connect.
4. **Usage & Budgets** shows spend cards, budget caps, and per-model limits
   (one provider per state: unavailable / live / balance / not configured).
5. **Advanced** folds the insight dashboards (Money Saved, Cost Firewall,
   Context Waste, Benchmark) behind a "Tools & insights" disclosure; tiles
   navigate out of Settings into the dashboard view.
