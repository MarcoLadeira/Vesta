# Workflow: open → ready

**Recording:** `recordings/01-open-ready.webm`
**Screens:** `screens/shell/SHELL-LAUNCH-001-fresh-launch.png`, `SHELL-MODEL-POP-002`, `SHELL-MODE-POP-003`, `SHELL-PALETTE-004`

1. The app boots into the chat shell with the new Vesta branding: a heart
   logo + **Vesta** wordmark in the top-left header, workspace switcher
   (`demo / main`), a centered live status line
   ("Auto mode · $0.42 today · $12.34 saved"), and header actions
   **Agents**, **+ New chat**, **Settings**, an Inspector toggle, and custom
   window controls (min/max/close).
2. The left sidebar is the chat list: **RECENT CHATS** with saved
   conversations and a **Clear history** action; the footer holds Settings
   and the provider status dots ("● Claude ● Codex ● / Copilot connected",
   "Local only · no telemetry").
3. The center pane shows the branded empty state — the heart mark, the
   headline **"The Living Flame."**, and three starter chips ("Summarize my
   changes", "Explain this repo", "Plan a safe refactor").
4. The composer placeholder reads "Tell Vesta what to build, fix, or
   explain…" with **Add context**, a composer-settings button, a **Team ⌄**
   toggle, **Auto ⌄** (run mode), **Auto model ⌄**, and **Send**.
5. Clicking the model button opens a popover with the account models
   (Claude · Opus 4.8, Codex · GPT-5.5, Copilot · GPT-5.4), free-tier models,
   the local model, and the **Vesta · Auto mode** routing entry with badges.
6. Clicking the mode button opens the run-mode popover: Ask, Plan,
   Approve Edits, Safe Auto, Auto-Accept Edits, Full Auto.
7. Ctrl+K opens the command palette overlay.
