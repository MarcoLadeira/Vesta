# Workflow: open → ready

**Recording:** `recordings/01-open-ready.webm`
**Screens:** `screens/shell/SHELL-LAUNCH-001-fresh-launch.png`, `SHELL-MODEL-POP-002`, `SHELL-MODE-POP-003`

1. The app boots straight into the chat shell: a left sidebar headed
   **RECENT CHATS** listing saved conversations ("How does routing work?",
   "Explain the budget guard") with a **Clear history** action, and a
   "Local only · no telemetry" footer with account status dots.
2. The center pane shows the branded empty state — the OPai mascot, the
   headline **"Better. Faster. Cheaper."**, and three starter chips
   ("Summarize my changes", "Explain this repo", "Plan a safe refactor").
3. The header shows workspace (`demo / main`), a live status line
   ("Auto · Auto · $0.42 today · $12.34 saved"), and a **+ New chat** button.
4. The composer sits at the bottom with the placeholder
   "Tell OPai what to build, fix, or explain…", an **Add context** button, and
   two selectors: model (**Auto**) and run mode (**Auto**), then **Send**.
5. Clicking the model selector opens a popover: a recommended **Auto** entry,
   a model/provider search box, and the model list (Claude · Opus 4.8,
   Codex · GPT-5.5, Copilot · GPT-5.4, Gemini · 3.1 Flash-Lite,
   Qwen 2.5 Coder · local) plus a **Manage models** link.
6. Clicking the mode selector opens a five-option popover: **Auto** (checked),
   **Manual**, **Accept edits**, **Plan**, **Bypass permissions**, each with a
   one-line plain-language description and a numeric shortcut hint.
