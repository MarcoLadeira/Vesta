# Phase 2 Roadmap

Implemented in the Phase 2 foundation:

- Project overlays in `.vestahub/project.json`.
- Tool and MCP enable/disable state.
- Registry validation.
- MCP config rendering.
- Safe workflow planning and mapped local execution.
- Health history.
- Local model discovery.
- Dashboard generation.

Remaining implementation steps:

1. Project overlays: add budget overrides, workflow overrides, and per-project notes editing.
2. Tool marketplace-style registry with richer search, tags, install recipes, and health history views.
3. Auto tool discovery from PATH, npm, Python venvs, Go bins, and MCP configs.
4. Installer scripts with project-local installs and license/cost checks.
5. Health monitoring with scheduled daily hub reports.
6. MCP orchestration with profile selection and launch supervision.
7. Local model integration through Ollama/LM Studio/llama.cpp style adapters.
8. Browser automation workflows with Playwright and screenshots.
9. Workflow scheduler for daily checks, dependency reviews, and context refreshes.
10. Dashboard UI for tools, cost, risks, tests, and project health.
11. Usage/cost analytics by workflow and project.
12. Project-specific agents and shared memory.
13. Sandboxed execution for shell tools.
14. Optional team mode and optional cloud sync.
