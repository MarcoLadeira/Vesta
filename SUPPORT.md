# Support

Vesta is `0.1.1` pre-alpha.

Use GitHub Issues for reproducible bugs and safety problems.

Use GitHub Discussions for:

- Questions.
- Ideas.
- Tool/plugin suggestions.
- Install help.
- Cost-saving workflows.

Before opening a new report, run:

```sh
op status
vesta doctor
vesta skills doctor
vesta models recommend "your task"
```
