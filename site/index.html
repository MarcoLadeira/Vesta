How it works

Deterministic first. Frontier last.

OPai collects local evidence before any model thinks, then routes to the cheapest tier that can actually do the job. Paid and cloud calls are gated by policy.

L0Deterministic tools + cached contextgit, scans, tests, reused evidence$0.00
L1Local small modelsummaries, classification, first-pass fixes$0.00
L2Cheap cloud modelconfirmed before use~$0.0015 / 1k
L3Strong frontier modelonly with evidence + confirmation~$0.012 / 1k
L4Max frontier modelexplicit escalation, gated~$0.045 / 1k

Team & Enterprise

      
Govern AI coding without banning the tools devs love.

      
Working controls, not slideware: a committed team policy, a tamper-evident audit trail, signed evidence, and a fail-closed CI gate.

      

        
opai team applyOne committed policy for the whole repo.

        
opai policy checkFail-closed CI gate. Exits non-zero on drift.

        
opai audit verifyHash-chained log; edits break the chain.

        
opai guard verifySigned, tamper-evident evidence packets.

60 seconds to first proof.

    
Windows PowerShell

    
irm https://raw.githubusercontent.com/MarcoLadeira/OPai/main/install.ps1 | iex

    
macOS / Linux

    
curl -fsSL https://raw.githubusercontent.com/MarcoLadeira/OPai/main/install.sh | sh

    
Then prove it

opai savings --markdown  # estimated AI spend saved on this project
opai share --markdown    # a savings badge for your README
